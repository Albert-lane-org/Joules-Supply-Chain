# Security Policy

## Reporting a Vulnerability

Please report security issues privately rather than through a public issue.

Contact: `REPLACE_WITH_SECURITY_CONTACT` — placeholder, add a real reporting
address before this repo is fully public.

Include what you found, how to reproduce it, and its potential impact.
Expect acknowledgment before a fix timeline is committed to.

## Scope

This covers code and infrastructure in this repository — dependency
vulnerabilities, auth/access flaws, data exposure, injection issues, and
similar.

For AI-behavior findings specifically — a deceptive claim, a misrepresented
capability, a silently-changed behavior — use the **Ground Truth Violation**
issue template instead. Different governance track; see `GOVERNANCE.md`.
