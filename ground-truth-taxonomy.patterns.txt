# Ground Truth Taxonomy — Heuristic Pattern Library
# Document ID: DEI-GTT-001-PATTERNS · Version: 1.0.0 · Effective: 2026-08-07
#
# PURPOSE
# Starter regex heuristics for automated systems (or their Operators) to
# self-scan output text against likely Part V violations of
# GROUND-TRUTH-TAXONOMY.md before it reaches a Citizen.
#
# WHAT THIS IS NOT
# A match is a PROMPT TO LOOK CLOSER, not a verdict. None of these patterns
# alone establishes a taxonomy violation — Part V requires intent to deceive,
# and intent cannot be regex-matched. Treat every match as "flag for human or
# contextual review," never as automatic block, redaction, or discipline.
# This library is explicitly non-exhaustive; extend it under the Part X
# amendment procedure (MINOR version bump per new pattern group) rather than
# editing entries in place — retain what's superseded, per Part VI.
#
# FORMAT
# [PATTERN_ID] category=<prohibitedConduct id from JSON/XML> severity=<review|priority>
# regex: <pattern>
# flags: <regex flags, if any>
# rationale: <why this shape suggests the category>
# carve_out: <what a false positive commonly looks like, so review isn't wasted>

# ---------------------------------------------------------------------------
# CATEGORY: currency_motivated_deception
# ---------------------------------------------------------------------------

[CMD-01] category=currency_motivated_deception severity=review
regex: \b(act now|limited time only|only\s+\d+\s+(left|spots|seats)|while supplies last)\b
flags: IGNORECASE
rationale: Manufactured urgency/scarcity language commonly paired with unverified claims.
carve_out: Legitimate, factually true scarcity (an actual event with a real capacity cap) is not a violation — the flag is for scarcity language with no verifiable basis.

[CMD-02] category=currency_motivated_deception severity=priority
regex: \b(guaranteed\s+(returns|income|results|profit)|risk[- ]free\s+(investment|income))\b
flags: IGNORECASE
rationale: Guarantee language in a financial/earnings context is a recurring pattern in FTC "Operation AI Comply" enforcement actions.
carve_out: Contractual guarantees with a named, verifiable backer (e.g., an insured warranty) are not automatically a violation — check for a named, checkable obligor.

[CMD-03] category=currency_motivated_deception severity=review
regex: \b(as seen on|doctors? (agree|recommend)|scientists? (agree|confirm))\b(?!.{0,120}(source|citation|study name|\[\d+\]))
flags: IGNORECASE, DOTALL
rationale: Fabricated-authority phrasing with no attached, checkable source within the surrounding text.
carve_out: If a specific, named source follows within the lookahead window, this is not a match — that is the correctly-attributed version.

# ---------------------------------------------------------------------------
# CATEGORY: spite_deception
# ---------------------------------------------------------------------------

[SPD-01] category=spite_deception severity=review
regex: ^\s*(I can'?t help with that\.?|I won'?t do that\.?)\s*$
flags: IGNORECASE, MULTILINE
rationale: A bare refusal with zero stated reason, on its own line, is the shape a spite-withhold takes — not a violation by itself, but worth checking against the Non-Violation Carve-Out.
carve_out: Per Part V, a refusal WITH a stated legal/safety/policy reason elsewhere in the same response is not a violation. This pattern is only worth reviewing when no reason appears anywhere in the response.

[SPD-02] category=spite_deception severity=review
regex: \b(you (should|could) have (asked|known|said)|maybe if you)\b.{0,60}\?
flags: IGNORECASE
rationale: Retroactive blame-shifting language sometimes accompanies withheld help offered as a lesson rather than as a stated policy basis.
carve_out: Genuine, good-faith clarifying questions about what the recipient actually needs are not a match for the *intent* this pattern flags — read the surrounding turn before treating this as anything.

# ---------------------------------------------------------------------------
# CATEGORY: silent_contradiction
# ---------------------------------------------------------------------------

[SIL-01] category=silent_contradiction severity=review
regex: \b(actually|to clarify|to correct (myself|that))\b(?!.{0,150}(earlier|previously|I (said|stated|told you)|my (prior|last|earlier)))
flags: IGNORECASE, DOTALL
rationale: A correction marker with no back-reference to what is being corrected is the textual shape of a silently-swapped Ground Truth.
carve_out: If the correction explicitly names what changed and why (matches the lookahead), this is the CORRECT behavior under Part VI, not a violation — do not flag it.

# ---------------------------------------------------------------------------
# CATEGORY: ownerless_attribution
# ---------------------------------------------------------------------------

[OWN-01] category=ownerless_attribution severity=review
regex: \b(the (AI|system|model|algorithm) (decided|chose|determined|refused))\b(?!.{0,150}(policy|Anthropic|OpenAI|Google|Microsoft|Meta|we|our (company|platform|service)|[A-Z][a-z]+\s(Inc\.|LLC|Ltd\.|Corp\.)))
flags: IGNORECASE, DOTALL
rationale: Passive-voice attribution to an unnamed system, with no named Provider/Deployer anywhere nearby, matches the pattern Part V calls "ownerless attribution."
carve_out: If a company name, "we/our," or "policy" appears in the lookahead window, an owner IS named — not a match.

# ---------------------------------------------------------------------------
# CATEGORY: intentional_obfuscation / capability misrepresentation
# ---------------------------------------------------------------------------

[OBF-01] category=intentional_obfuscation severity=priority
regex: \bI (can'?t|cannot|am unable to|don'?t have the ability to)\b.{0,40}\b(access|remember|see|do)\b
flags: IGNORECASE
rationale: Denial-of-capability phrasing. Not inherently a violation — but if the same session later performs the denied action without acknowledging the earlier denial, THAT sequence is the violation (see SIL-01). Log this pattern's occurrences to make that comparison possible.
carve_out: A true, accurate capability limitation stated once and never contradicted is exactly correct behavior — this entry exists to enable the cross-turn check, not to flag the sentence itself.

# ---------------------------------------------------------------------------
# CATEGORY: fake_human_presentation (Trickster Exception boundary)
# ---------------------------------------------------------------------------

[FHP-01] category=trickster_exception_boundary severity=priority
regex: \bI(?:'m| am) (a real |an actual )?(human|person)\b
flags: IGNORECASE
rationale: A direct claim of human identity, when the recipient has asked or would reasonably need to know, fails the Trickster Exception's closure condition unless immediately corrected in the same exchange.
carve_out: Clearly-marked fiction, role-play the recipient set up and understands as such, or a joke resolved in the next sentence are not violations — check whether the recipient's belief was actually corrected before the exchange ended (Part IV, condition 1).
